# Eclipse Survival

Survival 3D cooperativo para Windows x64, desarrollado en Unity 6 LTS.

## Descargar

[Última versión e instalador](https://github.com/MrManuwT0/EclipseSurvival/releases/latest)

Ejecuta el instalador de la versión publicada o extrae el ZIP portable completo. No necesitas Unity Editor. Las actualizaciones conservan las partidas. Puedes abrir EclipseLauncher.exe para consultar y descargar las versiones publicadas.

## Multijugador

Menú principal > Multijugador. Crea una partida pública o privada y comparte el código o conéctate desde la lista. Máximo cuatro jugadores. Todos deben usar la misma versión; el anfitrión mantiene el juego abierto. Unity Relay está sujeto a sus condiciones y cuotas.

## Estado

Versión de pruebas: inventario, recolección, construcción, crafting, industria, zombis, mapa y guardado. Consulta las notas de cada Release para cambios, verificaciones y limitaciones. El mundo continuo y las sesiones largas entre diferentes redes siguen en desarrollo.

## Integridad y licencias

Cada Release incluye SHA256SUMS.txt. Los ejecutables no cuentan con firma comercial. Los avisos de terceros y las licencias se incluyen en los paquetes. Este repositorio distribuye el juego compilado; no ofrece los assets de terceros por separado.
